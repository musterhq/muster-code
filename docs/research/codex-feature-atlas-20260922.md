# Codex product reference atlas — 22 September 2026

This is a source map for Muster Agent Mode, not an assertion about private Codex implementation details. **Observed** means visible in an official screenshot/video or the installed desktop app. **Documented** means OpenAI describes the behavior. **Inferred** is never an acceptance substitute.

Installed reference build: `/Applications/ChatGPT.app`, bundle `com.openai.codex`, version `26.915.31945`, build `9922`.

| Product area | Reference evidence | Codex behavior to preserve | Muster scope / open gap |
| --- | --- | --- | --- |
| Shell and work contexts | [Desktop migration](https://help.openai.com/en/articles/20001276/), [ChatGPT for ambitious work](https://openai.com/index/chatgpt-for-your-most-ambitious-work/) | Chat, Work and Codex are explicit contexts. Codex can remain the default. | NAV-01–04, NAV-13. Keep Agent Mode a separate top-level app and preserve folder/Project distinctions. |
| Projects, local folders and chats | [Projects and chats](https://learn.chatgpt.com/docs/projects) | Local projects can connect to folders; self-contained chats remain possible. Pin, rename, search, archive and restore are first-class. | NAV-03–08, CHAT-01–06, CHAT-16. Shared Project authority remains broader than Codex organization. |
| Composer commands and modes | [Slash commands](https://learn.chatgpt.com/docs/reference/slash-commands), [Settings](https://learn.chatgpt.com/docs/reference/settings) | `/` filters actions; `$` invokes skills. Documented commands cover model, reasoning, Project, task, side task, plan, goal, review, MCP, memories, worktree and status. Follow-ups can steer or queue. | CMP-01–23, CHAT-03–05/09/15/17. Controls must be context-aware and unavailable actions truthful. |
| Subagents and thread coordination | [Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents), [Codex app launch](https://openai.com/index/introducing-the-codex-app/) | Specialized agents work in parallel; supported clients open child threads and review results in the originating work. | TRN-10–11, PRJ-04–07, SBX-12–13. Avoid noisy intermediate duplication and overlapping writers. |
| Streaming runtime and reconnection | [App Server architecture](https://openai.com/index/unlocking-the-codex-harness/) | A long-lived, bidirectional JSONL/JSON-RPC-lite server emits UI-ready progress and diff notifications and persists thread event history for reconnect. | TRN-01–09/12–18, PER-02/14. Muster needs bounded live deltas, checkpoints, exact final text and recovery. |
| Worktrees, Git, diffs and review | [Worktrees](https://learn.chatgpt.com/docs/environments/git-worktrees), [Codex app launch](https://openai.com/index/introducing-the-codex-app/) | Isolated Git worktrees, inline review, editor handoff and checkout/worktree movement are visible workflows. | DIF-01–12, GIT-01–13, NAV-10. Worktrees are Git isolation, not security sandboxes. |
| Documents, sheets, slides and PDFs | [Artifacts viewer](https://learn.chatgpt.com/docs/artifacts-viewer), [Office creation/editing](https://help.openai.com/en/articles/20001278-creating-and-editing-documents-spreadsheets-and-presentations-with-chatgpt-work) | Office/PDF/HTML previews stay beside chat; supported previews allow selecting content for revision. CSV is a table; Markdown, formulas/cells, PDFs and slides have format-aware presentation. | WRK-01–18, DIF-10–11. In-app fidelity is required; installed Microsoft 365 is not documented as the preview backend. |
| Browser, annotations and computer use | [Built-in browser](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app), [Browser](https://learn.chatgpt.com/docs/browser), [Computer use](https://learn.chatgpt.com/docs/computer-use), [Appshots](https://learn.chatgpt.com/docs/appshots) | The browser has its own state, tabs, approvals and annotation flow. Appshots include the frontmost app screenshot and available text. | BRW-01–06, CUA-01–09, WRK-12. Persistent PiP is a Muster requirement and still needs its own implementation/evidence. |
| Plugins, skills, apps and MCP | [Plugins](https://help.openai.com/en/articles/20001256/), [Customization overview](https://learn.chatgpt.com/docs/customization/overview) | Users review a plugin’s skills/apps, install it and authorize accounts. Skills, app authorization and MCP connection are separate concepts. | EXT-01–15, CMP-09–12/17. Inventory is live; executable lifecycle, permissions and connection health remain open. |
| Memory | [Memories](https://learn.chatgpt.com/docs/customization/memories) | Per-chat memory controls and global settings manage recall and future contribution; background local memory uses summaries, durable entries and evidence with secret redaction. | MEM-01–15. Advanced Hindsight entities, reflection jobs and bank lifecycle remain separate acceptance work. |
| Scheduling and long-running work | [Scheduled tasks](https://learn.chatgpt.com/docs/automations), [Long-running work](https://learn.chatgpt.com/docs/long-running-work), [Notifications](https://learn.chatgpt.com/docs/notifications) | Scheduled work has active/paused/completed runs; notification policy separates completion from permission/question alerts. | AUT-01–10, CHAT-13–15, TRN-15, PRJ-09–10. Scheduler is not yet live in Agent Mode. |
